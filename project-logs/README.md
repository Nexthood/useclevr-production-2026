# Project Logs

This folder stores project-level records outside the documentation knowledge base.

## Files

- [Interactive log](interactive-log.md): detailed AI work sessions, decisions, findings, and learning.
- [Activity log](activity-log.md): compact current activity summary for developers and operators.

## Rules

- Update both logs after every completed AI interaction.
- Keep the interactive log detailed enough to preserve decisions and evidence.
- Keep the activity log short, current, and grouped by date.
- Store reusable prompts in [project-prompts](../project-prompts/README.md).
- Store durable AI behavior and collaboration guidance in
  [docs/AI-interaction](../docs/AI-interaction/README.md).
- Never store credentials, raw customer data, uploaded datasets, or private environment values.
