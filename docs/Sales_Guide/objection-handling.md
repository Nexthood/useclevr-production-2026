# Objection Handling

## Data Accuracy

UseClevr keeps AI answers grounded in uploaded dataset context and shows setup progress so missing
business context is visible.

## Setup Effort

Users start with CSV upload and add business profile details over time. Progress actions show the
next useful setup step.

## Security

Uploaded data, authentication, payment setup, and deployment readiness have dedicated developer
requirements and validation checks.

## Accounting Scope

Accountancy focuses on bookkeeping workflow readiness: reconciliation, expense coding, receipts,
monthly close, tax preparation, and compliance checks.

## Deployment Trust

Production deployment uses generated output, Railway health checks, and local generated-server smoke
tests before publishing deployment branches.
