# AI Learning Traces

Use this folder for guidance about interaction traces that educate users, mark problems, and capture improvement suggestions.

## Guides

- [Interaction trace guide](interaction-trace-guide.md)
- [Interaction trace prompt](../prompt-library/interaction-trace-learning.md)

## Trace Rule

- A useful trace explains what happened, what the user can learn, what problem was marked, and what improvement comes next.
- A trace is not a raw transcript.
- A trace never stores secrets or sensitive source data.
