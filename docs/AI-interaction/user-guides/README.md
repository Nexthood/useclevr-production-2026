# User AI Guides

Use this folder for user-facing guidance about asking AI questions, reading AI responses, reviewing history, and learning from AI interactions.

## Guides

- [Bookkeeping user guide](bookkeeping-user-guide.md)

## User Rule

- Tell users what the product does now.
- Explain what data AI uses and what data stays private.
- Help users write better requests and interpret AI answers.
- Keep implementation details out unless they help users avoid a concrete risk.
