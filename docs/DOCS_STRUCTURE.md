# Documentation Structure

Use this map to choose the right document location.

## Top-Level Areas

| Area                                           | Audience                     | Purpose                                           |
| ---------------------------------------------- | ---------------------------- | ------------------------------------------------- |
| [User_Guides](User_Guides/README.md)           | End users                    | Product workflows and help guidance               |
| [Developer_Guides](Developer_Guides/README.md) | Developers, AI agents        | Setup, architecture, deployment, implementation   |
| [AI-interaction](AI-interaction/README.md)     | Users, developers, AI agents | AI collaboration rules and trace guidance         |
| [Sales](Sales/README.md)                       | Sales, marketing             | Sales documents, project planning, marketing plan |

## Placement Rules

- User-facing how-to content goes in `docs/User_Guides/`.
- Accessibility and display guidance goes in `docs/User_Guides/accessibility.md`.
- Implementation and deployment guidance goes in `docs/Developer_Guides/`.
- AI behavior and collaboration guidance goes in `docs/AI-interaction/`.
- Reusable prompt patterns go in `project-prompts/`.
- Detailed session records and activity summaries go in `project-logs/`.
- Sales material and project documents go in `docs/Sales/`.
- Implementation tasks go in `.TODO/todo-next.md`.
