# E-signature provider assessment

Evidence reviewed 2026-11-11. Prices are published USD entry points, before tax and optional services. They do not constitute a quote or purchase authorization. API plans differ from ordinary human-seat signing subscriptions; confirm the exact required API/webhook/audit entitlements with the provider before buying.

Effective unit examples divide the displayed plan fee by included volume, assuming full use. They are not marginal overage quotes. SMS, identity verification, QES/trust services, branding, support, extra envelopes and taxes can add cost. Two signers on one agreement need not consume two agreement transactions; verify the selected provider's counting rules. Provider-account usage outside this integration also consumes quota. Dropbox documents automatic upgrades when API request allowances are exceeded; approve the budget, account settings and monitoring before enabling binding sends.

## Recommendation

Prefer **Dropbox Sign with native hosted sequential signing**, subject to owner approval and the exact plan's acceptance test. Its documented ordered signers, free non-binding test mode, authenticated callbacks, appended audit trail and direct signed-PDF retrieval fit this two-party lifecycle without an embedded signing UI or custom signature ceremony. The code provides this production adapter plus the provider-neutral interface and an explicitly non-binding local mock. It does not implement production adapters for the other three providers.

This recommendation is an engineering judgment from the capabilities above, not a conclusion that Dropbox is always cheapest or that a basic email signature satisfies every jurisdiction. DocuSign is attractive where stronger assurance/ecosystem procurement is already required; SignWell may be economical at low volumes after a written transaction quote and security review; Adobe is appropriate where an existing enterprise agreement supplies API access. If counsel requires qualified signatures, approved identity validation or regional processing that the selected plan cannot deliver, keep live signing disabled and implement the approved alternative assurance flow.

Provider marketing compliance claims are not a legal opinion for these agreements. Owner/counsel approval must cover retention of provider transaction metadata as well as document deletion, international transfers, DPA/SCCs, subprocessors, breach handling, account MFA and authorized signer controls. Local encrypted storage supplements the provider evidence; it does not make an ordinary signature qualified.
