# Future AI Collaboration Guidelines

## S-1 Before Editing

- A-1 Read project instructions and inspect current worktree status.
- A-2 Identify whether changes are user-visible, developer-only, or deployment-only.
- A-3 Add a TODO task before confirmed implementation work starts.

## S-2 During Work

- A-1 Prefer current code patterns over copying old files directly from history.
- A-2 Keep changes scoped to the requested behavior.
- A-3 Verify with typecheck, lint, and build when routes or shared UI change.

## S-3 Closing Work

- A-1 Move completed tasks to todo-done.
- A-2 Update requirements for user-observable product behavior.
- A-3 Update changelog with active, user-facing language.
- A-4 Report remaining risks or deferred work without marking it complete.
